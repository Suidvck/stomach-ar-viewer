# Stomach 3D WebAR Viewer

Image Tracking WebAR Viewer built with **MindAR** and **Three.js** for the Digestive System (Stomach) card.

- **3D Model:** Human Stomach (CC0 1.0, Grab3D) — decimated to ~40k triangles with Draco compression (~442 KB).
- **Usage:** Host on HTTPS (Vercel / GitHub Pages) or `http://localhost`, then tap **เปิดกล้อง AR** and point the camera at the Stomach card.
